How to Connect Any Google Form to This System

Follow these 4 simple steps to have responses flow in automatically.

1

Create your Google Form

Go to Google Forms and create a form with a text question (e.g. "Please share your feedback or tweet").

2

Link Form to Google Sheets

Inside your form, click the Responses tab and click Link to Sheets. This creates the spreadsheet where new rows appear.

3

Open Apps Script

In the spreadsheet, click Extensions → Apps Script. Replace the empty function with the script below.

4

Add "On Form Submit" Trigger

Click the Triggers icon (clock) on the left sidebar → Add Trigger → Select onFormSubmit → Event Type: On form submit → Save.

Google Apps Script Code: 
function onFormSubmit(e) {
  // e.values contains: [Timestamp, Name, FeedbackText, ...]
  // Change index 2 to match the column index of your feedback question (0-indexed)
  var feedbackText = e.values[2];
  var respondent = e.values[1] || "Anonymous";

  // URL of your FastAPI server (use ngrok or public IP during testing)
  var apiUrl = "https://YOUR_DOMAIN_OR_NGROK_URL/api/form-submission";

  var payload = {
    feedback_text: feedbackText,
    respondent: respondent
  };

  var options = {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  };

  try {
    var response = UrlFetchApp.fetch(apiUrl, options);
    var data = JSON.parse(response.getContentText());

    // Write back Sentiment & Confidence into the Google Sheet automatically!
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var lastRow = sheet.getLastRow();
    sheet.getRange(lastRow, 4).setValue(data.sentiment);   // Column D: Sentiment
    sheet.getRange(lastRow, 5).setValue(data.confidence);  // Column E: Confidence
  } catch (err) {
    Logger.log("Error invoking sentiment API: " + err);
  }
}
